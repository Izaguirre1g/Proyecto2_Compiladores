# Documentación de funciones — `ir.c`

**Ruta en el proyecto:** `src/Representacion_Intermedia/ir.c`  
**Propósito general:** convertir el AST de BAL en una representación intermedia de tres direcciones (IR), generar temporales y etiquetas, y construir los bloques básicos y el CFG.

> Las líneas indicadas son las líneas iniciales de las definiciones de función en el archivo fuente. Las funciones `static` son auxiliares internas del módulo.

## Funciones

| Línea | Función | Qué hace |
|---:|---|---|
| 12 | `hijo` | Obtiene el hijo del AST ubicado en el índice indicado. |
| 19 | `copia` | Reserva una copia independiente de una cadena para que la IR no dependa de la memoria del AST. |
| 28 | `nombre` | Genera nombres internos con prefijo, como `$tN` para temporales y `$LN` para etiquetas. |
| 35 | `error` | Registra el primer error de generación de IR y muestra la ubicación del nodo AST que lo provocó. |
| 44 | `emitir` | Agrega una instrucción `IrInstr` al arreglo dinámico de la IR. Duplica sus operandos y operador, conserva la línea de origen y gestiona el crecimiento del arreglo. |
| 70 | `temporal` | Genera el siguiente temporal virtual `$tN`, incrementando el contador del programa y controlando desbordamientos o fallos de memoria. |
| 77 | `etiqueta` | Genera una etiqueta de control `$LN` única para saltos, ciclos y uniones de ramas. |
| 85 | `referencia` | Convierte un identificador o acceso indexado en una referencia lógica. En un índice emite `IR_INDEX_REF`, pero no lee el valor almacenado. |
| 108 | `inicializar_coleccion` | Recorre recursivamente un literal de colección y genera referencias y `IR_STORE` para inicializar sus elementos en el orden del literal. |
| 134 | `declarar_arreglo` | Emite la declaración del arreglo (`IR_ARRAY_DECL`), registra cada dimensión con `IR_ARRAY_DIM` y procesa el inicializador si existe. |
| 159 | `expresion` | Traduce una expresión AST a un operando IR. Los operadores compuestos producen temporales; admite literales, identificadores, índices, `size`, operaciones binarias/unarias y llamadas locales. Implementa cortocircuito para `&&` y `||`. |
| 246 | `condicional` | Traduce `whether`, `alif` y `also` a pruebas condicionales, saltos y etiquetas que unen las ramas. |
| 267 | `sentencia` | Traduce sentencias y bloques a IR. Maneja declaraciones, asignaciones, listas, condicionales, `whale`, `cycle`, retornos y llamadas usadas como sentencias. |
| 397 | `desde_ast` | Ejecuta la generación completa desde un AST. Recorre las funciones, emite declaraciones de parámetros y sentencias, opcionalmente crea una función de inicialización global y construye el CFG. Si falla, libera la IR parcial. |
| 443 | `ir_desde_ast` | API pública que genera IR desde el AST usando el modo histórico, que no procesa declaraciones globales. |
| 447 | `ir_desde_ast_programa` | API pública que genera IR desde el AST permitiendo el tratamiento de declaraciones globales mediante la función especial de inicialización. |
| 452 | `ir_liberar` | Libera las cadenas de cada instrucción, el arreglo de instrucciones, los sucesores del CFG y los bloques. Deja la estructura `IrPrograma` en cero. |
| 465 | `sucesor` | Agrega un sucesor a un bloque básico sin duplicarlo. Limita el número de sucesores al máximo contemplado por el CFG de esta IR. |
| 474 | `ir_bloques_basicos` | Identifica líderes de bloques, crea los intervalos `[inicio, fin)` y conecta sus sucesores según saltos y continuidad. No enlaza implícitamente el final de una función con la siguiente. |
| 521 | `ir_imprimir` | Imprime los bloques, sus sucesores y las instrucciones IR en un formato legible. No ejecuta la IR ni genera instrucciones físicas. |

## Flujo general

`ir_desde_ast` / `ir_desde_ast_programa` → `desde_ast` → `sentencia` y `expresion` → `emitir` → `ir_bloques_basicos`.

## Consideraciones

- Los temporales `$tN` son virtuales y no representan registros físicos.
- La IR conserva nombres simbólicos y ubicaciones de origen.
- Las operaciones de arreglos y listas son abstractas; no equivalen automáticamente a accesos LSU físicos.
- El generador no enlaza por sí solo los cuerpos de módulos importados.
