Grafo de dependencias del reordenamiento

Genera el JSON con ./balc --reorder-json reordenamiento/pruebas/01_war.bal > 01_war.grafo.json (o ./balc --unroll --reorder-json … para ver el grafo después del loop unrolling). Cada caja es una instrucción del bloque y cada flecha una dependencia: la de arriba tiene que ir antes que la de abajo. La ruta crítica es la cadena más larga de esperas: ningún orden puede ser más corto que ella.

Línea de tiempo (un ciclo por casilla)

Cada casilla es un ciclo del procesador. Las rayadas son esperas (NOPs): el valor que se necesita todavía no está listo. El reordenamiento llena esos huecos con instrucciones independientes.

El archivo se lee únicamente en este navegador. No necesitas conexión a Internet.
